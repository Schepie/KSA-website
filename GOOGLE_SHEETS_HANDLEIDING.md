# ✏️ KSA Zonhoven - Rechtstreeks Website Beheer ("Edit Mode")

De website van KSA Zonhoven (zowel computer als mobiel) kan rechtstreeks op de pagina zelf worden aangepast door de leiding via de ingebouwde **Bewerk-modus (Edit Mode)** en wordt rechtstreeks opgeslagen in GitHub!

---

## 1. Hoe activeer je de Edit Mode op de website?

1. Scroll helemaal naar beneden op de website (in de donkere balk onderaan, of op mobiel onderaan het tabblad **Info**) en klik op de blauwe knop **`✏️ Bewerk Website (Edit Mode)`** *(of typ `?edit=1` achter het webadres)*.
2. Vul de pincode voor de leiding in (standaard pincode: **`ksa2026`** — zelf aanpasbaar via de knop *⚙️ GitHub Koppeling*).
3. Onderaan het scherm verschijnt nu de **Bewerk-werkbalk**.

---

## 2. Wat kun je rechtstreeks op de pagina aanpassen?

* **📝 Teksten aanpassen**: Klik gewoon op eender welke titel, alinea, statistiek, datum, uur of groepsbeschrijving (`Kabouters`, `Sloebers`, `Roodkapjes`, `JIM`, `SIM`, `KIM`) op de website en typ direct je aanpassing.
* **📸 Foto's wijzigen (zonder URL)**: Klik rechtstreeks op een foto op de website &rarr; kies een nieuwe foto van je computer of smartphone &rarr; de foto wordt direct op de pagina vervangen en bij het opslaan automatisch toegevoegd aan de map `images/uploads/` in GitHub!
* **🔗 Knoppen & Links aanpassen**: Klik op een actieknop (bv. *"Bestel Kaarten"*) om de tekst op de knop, de URL-link of de zichtbaarheid (tonen/verbergen) te wijzigen.
* **⏱️ Event Banner & Aftelklok**: Bovenaan de Event Banner verschijnt in Edit Mode een gele balk waarmee je via een kalender-kiezer direct een nieuwe datum en tijd voor de aftelklok instelt, of de volledige banner met één klik verbergt/toont (`🎯 Banner Aan/Uit`).
* **➕ Kaartjes toevoegen, op `'Voorbij'` zetten of verwijderen**: Onder elk kalender-item, nieuwsbericht en leidingspaspoort verschijnen in de Edit Mode knoppen om een nieuw item toe te voegen (`➕`), een activiteit op **`🏁 Voorbij`** of **`🔥 Nu`** te zetten, of te verwijderen (`🗑️`).
* **📅 Automatische `'Voorbij'`-datumcontrole**: Daarnaast controleert de website bij elk bezoek automatisch de huidige datum en zet gepasseerde kalenderdata en evenementen vanzelf op **`Voorbij`**.

---

## 3. Opslaan & Publiceren naar GitHub (`Schepie/KSA-website`)

1. Klik in de bewerk-werkbalk onderaan eenmalig op **`⚙️ GitHub Koppeling`**.
2. De repository staat al ingesteld op **`Schepie/KSA-website`** (branch `main`). Plak daar eenmalig een GitHub Personal Access Token met *Contents: Read and write* rechten.
3. Klik op de groene knop **`💾 Opslaan naar GitHub`** om alle aanpassingen en geüploade foto's rechtstreeks live te publiceren!
